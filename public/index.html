Cómo jugar con un mando Bluetooth

Mando Bluetooth: palanca izquierda o cruceta para moverte · A / ✕ para saltar y confirmar · X / □ para golpear · B / ○ o RT / R2 para lanzar · R1 / L1 para defender · Start / Options para pausar. Conecta el mando desde los ajustes del dispositivo y pulsa un botón. Requiere un mando reconocido por el navegador con distribución estándar.

Conoce los peligros del sendero

Peligros del sendero: tarántulas, serpientes, alacranes y chichicaste. Evita tocarlos; el chichicaste es una planta urticante y no puedes aplastarla saltando. Despéjala con tu poder.

Recoge oro, jade y obsidiana. Cada intento empieza con cinco corazones de salud. Tienes tres intentos y un punto de control antes del jefe. En celular, gira el dispositivo horizontalmente para jugar con ambos pulgares. También puedes usar un mando compatible. Si se desconecta durante el juego, la partida se pausa.
